# Sistema de Controle de Exames Médicos

Front-end de um sistema de controle de exames médicos, com agendamento de exames laboratoriais e de imagem e acompanhamento de status.

## Tecnologias

- HTML5
- CSS3
- JavaScript


## Entregas (Sprints)

- **Sprint 1:** Tela inicial (apresentação, identidade visual e acesso ao sistema)
- **Sprint 2:** Tela de login (campos de usuário e senha, validação do formulário e navegação para a tela principal)
- **Sprint 3:** Tela principal com menu de navegação para as funcionalidades do sistema
